# basis-ui app

A UI on `@basis/ui` and `@basis/parallax`. Replace this line with what the app is for, who uses it, and which API it
calls.

```sh
vp install      # once per clone: the dependencies and the git hooks
vp dev          # the app in fixture mode, with no API, at the address it prints
vp run verify   # every check, each failure an ERROR line with its fix
vp build        # dist/, which the Dockerfile's image serves
```

`AGENTS.md` is the map of the repo for a person and an agent alike: the sample API and how to replace it, how to name
the app, and basis-ui's checks and tasks. `vp run docs` prints `@basis/ui`'s docs for the installed version, its Getting
started and On Windows among them.
